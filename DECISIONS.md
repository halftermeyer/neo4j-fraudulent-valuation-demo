Key choices:
    - **FastPath reimplemented** (`scripts/fastpath.py` + `app/src/lib/fastpath.ts`, byte-mirrored): the test oracle is the PUBLISHED worked example the user supplied in `inputs/fastpath_worked_example.md` (Neo4j PS deck) — golden vector (0.8586, 0.2750, 0.5971, 0.5294), both intermediate event embeddings, +100-day shift equivariance, all to 4 decimals; the example pins the ambiguous semantics (strict `0 < elapsed ≤ Θ` filter, smoothing normalised over the boundary-TRUNCATED ±s window, kernel distance from the RAW elapsed time). Trajectory atoms restricted to SIGNAL-bearing labels (override/change/escalation/PnL/approval + roles + desk + gap rule ids): the routine compliance heartbeat (monthly IPV, periodic MAP, Control) is shared by everyone and swamps the discriminative dimensions.
